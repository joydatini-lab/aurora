
## Audit système de thèmes (branche `audit/themes-multipalette-gradients`, commit 26b95c2)

Mission : auditer le theming existant + écrire `docs/design-system/integration-palettes-gradients.md`
(plan d'intégration multi-palette/multi-gradient). Livrable = 1 doc, aucune couleur inventée.

### Faits vérifiés (re-découvrables mais coûteux : les noter)
- Chaîne réelle : 13 JSON (`packages/ui/src/themes/*.json`) → `themes/index.ts`
  (`THEMES` l.32-43, `PRESETS` l.46-50) → `resolve.ts` `resolveToken` (l.121-215) /
  `resolveThemeCSSVars` (l.218-263) / `toShadcnVars` (l.271-297) → `theme/provider.tsx`
  (écrit inline sur `<html>`, l.125-132). Monté par `apps/mobile/src/main.tsx:146-155`
  (via `FocusThemeAdapter`), `apps/web-app/src/main.tsx:21-23`, Storybook preview.
- **`--aurora-theme-gradient` est un TOKEN MORT côté UI** : émis (`resolve.ts:237-238`,
  fallback `tokens.css:109`) mais **zéro `var(--aurora-theme-gradient)` dans tout le
  dépôt**. La vignette `/settings` appelle `gradientCSS()` en JS direct
  (`apps/mobile/src/pages/settings/index.tsx:114`), pas la variable CSS. Seuls
  consommateurs = 2 fichiers de test. Constat majeur pour toute intégration de gradient.
- **1 seul gradient par thème** : clé JSON singulière `gradient` (`types.ts:117-122`).
  La clé plurielle `gradients` (`aurora.json:24`) est une **chaîne descriptive**, jamais
  parsée (`grep -rn "\.gradients"` → 0 hit en code). 10 thèmes expressifs ont `gradient`,
  les 3 presets non.
- **2 formes Tailwind v3** : `packages/ui/tailwind.config.ts` mappe sur triplets HSL
  `hsl(var(--aurora-*-h))` (statiques, écrits dans `aurora.css:20-48`/`.dark:53-76`,
  PAS émis par le provider) ; `apps/mobile/tailwind.config.js` + `apps/web-app/tailwind.config.ts`
  mappent sur valeurs pleines `var(--primary)` (forme qui marche avec le provider).
- **A11y déjà outillée** : `hexLuminance` (resolve.ts:72), `contrastRatio` (:85),
  `accentInk` (:99), exportés (`index.ts:30-33`). Tests : `theme-dark.test.ts` (colorsDark
  requis + surface dark < 0.55, sémantiques immuables), `theme-gradient.test.ts`
  (≥2 stops hex, gradients distincts), `theme-css-vars-naming.test.ts` (forme TIRET
  obligatoire), `tokens-css-drift.test.ts` (tokens.css non dérivé du SSoT).
- **Incohérence d'affichage pré-existante** : `settings/index.tsx:73-75` `GRADIENT_FAMILY`
  = 5 thèmes (aurora/lagoon/cosmos/vesper/solara) mais les 10 expressifs ont un `gradient`.
  Catégorisation DISPLAY-ONLY assumée (commentaire l.69-70), pas un bug de données.
