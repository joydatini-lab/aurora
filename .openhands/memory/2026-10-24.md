### agent-server file upload 422 (diagnostic complet, déplacé depuis MEMORY.md)
L'agent-server tourne sur `127.0.0.1:60000` (v1.58.1). Clé de session : la lire dans l'env du
processus, ne pas la deviner :
`KEY=$(tr '\0' '\n' < /proc/38/environ | grep '^SESSION_API_KEY=' | cut -d= -f2-)`
(à passer en `X-Session-API-Key` ; ne jamais l'afficher).
Deux endpoints : `POST /api/file/upload` (non scopé) et
`POST /api/conversations/{cid}/file/upload` (scopé). Les deux prennent `?path=<ABSOLU>` +
le champ multipart `file`.
**L'endpoint scopé refuse tout chemin hors de la racine du workspace de la conversation.**
Reproduit (cid b8590c8b…, workspace `/workspace/project`) :
`/workspace/project/x` → 200 · `/workspace/project/../project/x` → 200 · `x` → 422 ·
`./x` → 422 · `/tmp/x` → 422 · `/workspace/x` → 422 ·
`/workspace/conversations/<cid>/x` → 422 · `/home/openhands/x` → 422.
L'endpoint non scopé n'a pas cette restriction (`/workspace/x` → 200).
Donc le 422 signifie que le CLIENT a envoyé un chemin relatif ou hors workspace (p. ex. il
supposait le dossier par conversation `$OH_CONVERSATIONS_PATH/<cid>/`). **Pas un bug Aurora.**

### The headline trap
~31 `react-hooks/*` errors were reported but **the plugin was never installed**. ESLint fails on
`eslint-disable-next-line react-hooks/...` directives whose rule is unresolvable, reporting
"Definition for rule 'react-hooks/exhaustive-deps' was not found" as an ERROR. So 26 of the 31
"violations" were artifacts of missing directives' rules, not code problems.
`eslint --print-config <file>` was the decisive tool: it showed `plugins: [@, @typescript-eslint,
import, storybook]` with `react-hooks` absent, while the run still reported react-hooks ruleIds.

### Real bugs found (not lint noise)
1. `apps/mobile/src/ux/use-horizontal-swiper.ts` imported `useReducedMotion` from `motion/react`
   — a genuine AD-10 violation (engines are restricted to packages/ui). Fixed by exporting
   `useReducedMotion` from `packages/ui/src/motion.tsx` (it was a private function) and importing
   from `@aurora/ui`.
2. `knowledgeFlags` / `emptyFlags` / `taskFlags` in 3 mobile pages called hooks but were not named
   `use*` — genuine `rules-of-hooks` violations. Renamed to `useKnowledgeFlags` / `useEmptyFlags` /
   `useTaskFlags`.
3. 6 genuine `exhaustive-deps` warnings in packages/ui, invisible until the plugin was installed:
   heat-graph (useMemo with a dep that didn't drive the value → useState), SemanticTreeRenderer
   (drop `effectiveVisible`, not an input to the dagre layout), MathRenderer (`onError` missing),
   AudioPlayer (5 handler props missing), use-file-upload (`onError` missing), AnimationController
   (depended on `key` instead of the `animate` callback it calls).
