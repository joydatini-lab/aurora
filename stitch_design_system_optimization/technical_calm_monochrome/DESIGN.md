## Brand & Style

This design system embodies "Technical Calm": a disciplined, hyper-functional aesthetic engineered for dense data visualization, mission-critical operations, and enterprise software. It recedes into the background, stripping structural noise so raw information takes absolute priority.

The core philosophy rests on an uncompromising monochrome foundation where structural chrome—canvas, containers, panels, and borders—is never tinted with brand colors. Chromatic color is treated as a finite, precious resource reserved exclusively for primary interactive affordances, focus rings, toggles, and active state indicators.

The design movement combines **Minimalism** with **Modern Enterprise Precision**:
- **Strict Neutral Purity**: Crisp slate-zinc values structure all layouts, avoiding ocular fatigue during extended workflows.
- **Micro-Contrast Over Ornamentation**: Hierarchy relies on refined typographic scale, crisp 1-pixel borders, and subtle luminance steps rather than saturated backdrops or heavy drop shadows.
- **Dynamic Thematic Adaptability**: While structural foundations remain strictly monochrome, the system accommodates 14 switchable accent themes, engineered to maintain WCAG 2.1 AA contrast fidelity across both light and dark environments.

## Colors

The color architecture enforces a total separation between structural containers and interactive accents. 

### Neutral Foundations
- **Light Mode**: Built upon pure `#FFFFFF`. The canvas and internal surfaces share the same clean white plane, structured purely via structural borders (`#E4E4E7` and `#D4D4D8`).
- **Dark Mode**: Employs an exact four-tier stepped luminance model:
  - Canvas: `#0A0A0A`
  - Structural Rails & Bars (L1): `#121212`
  - Cards & Content Surfaces (L2): `#18181B`
  - Modals & Floating Popovers (L3): `#222226`

### Typography Neutral Mapping
- **Primary Text**: `#09090B` (Light) / `#FAFAFA` (Dark) ensures immediate optical contrast exceeding 14:1.
- **Secondary Text**: `#52525B` (Light) / `#A1A1AA` (Dark) maintains 4.5:1+ for descriptive captions.
- **Muted Text**: `#71717A` shared across both modes for non-critical column keys and subtle indicators.

### Dynamic Accent Tokens
The system uses Sky Blue as the default accent (`#0284C7` Light, `#38BDF8` Dark), with built-in runtime tokens for all 13 additional functional palettes. Accent colors must never be applied as broad panel backgrounds. Their usage is strictly confined to:
1. Primary action buttons (`CTA`)
2. Form field focus rings (`focus:ring-2`)
3. Switch toggles and active segment markers
4. Active table row borders (`2px solid` left indicator)

## Typography

The typographic hierarchy uses a dual-font structure:

- **Inter**: Drives all structural UI, editorial headings, labels, and communicative text. With clean geometric proportions, neutral curves, and tall x-height, it remains legible in dense, nested component trees.
- **JetBrains Mono**: Assigned to tabular values, analytics metrics, units of measurement, timestamps, technical code fragments, and KPI readouts. Its monospaced figures prevent layout shifts when real-time numbers stream into views.

### Tracking and Metric Rules
- Headings larger than 24px must use negative letter-spacing (`-0.01em` to `-0.025em`) to preserve compact visual weight.
- Tabular numeric displays must enable proportional figure alternates or tabular numerals (`font-variant-numeric: tabular-nums;`) to guarantee column alignment across data grids.

## Layout & Spacing

This design system uses a 12-column fluid grid system pinned to an 8px base rhythm (with a 4px sub-grid for dense micro-components like compact badges and inputs).

### Form Factors & Breakpoints
- **Mobile (< 768px)**: 4-column fluid layout. Canvas margins set to `1rem` (`margin`), gutters at `1rem` (`gutter`). Toolbars collapse into drawer sheets; multi-column KPI clusters stack into single-column rows.
- **Tablet (768px – 1023px)**: 8-column fluid layout. Margins expand to `1.5rem` (`margin-tablet`). Master-detail layouts split horizontally.
- **Desktop (≥ 1024px)**: 12-column structured layout. Outer margins set to `2rem` (`margin-desktop`) with `1.5rem` (`gutter-desktop`). Content areas may span 2, 3, 4, 6, 8, or 12 columns with standard max-width caps at 1440px or extend to 100% fluid in dashboard consoles.

### Internal Component Spacing
- Micro components (inline tags, pills, compact buttons): `space-xs` (4px) to `space-sm` (8px).
- Input blocks, table cell padding, list items: `space-sm` (8px) vertical, `space-md` (16px) horizontal.
- Card interiors and panel separation: `space-md` (16px) to `space-lg` (24px).

## Elevation & Depth

Visual depth avoids heavy skeuomorphic drop shadows. Instead, it relies on an **asymmetric mode strategy**:

### Light Mode: Low-Contrast Precision Hairlines
Light mode avoids elevation stacking. The canvas, panels, and cards all reside on `#FFFFFF`. Depth is created strictly via 1px structural borders:
- Rest tier: `1px solid #E4E4E7` (Border Subtle)
- Interactive and active container bounds: `1px solid #D4D4D8` (Border Strong)
- Primary CTA Buttons receive a micro ambient shadow for tactile affordance: `0 1px 2px 0 rgba(0, 0, 0, 0.05)`.

### Dark Mode: Stepped Luminance Stack
In dark mode, physical depth is conveyed through deliberate luminance stepping combined with subtle hairlines:
- **Canvas Base**: `#0A0A0A`
- **Surface Level 1** (Sidebars, navigation rails, headers): `#121212` with `1px solid #27272A`
- **Surface Level 2** (KPI cards, content modules, tables): `#18181B` with `1px solid #27272A`
- **Surface Level 3** (Floating dialogs, popovers, context menus): `#222226` with `1px solid #3F3F46` plus an ambient boundary shadow: `0 10px 25px -5px rgba(0, 0, 0, 0.6)`.

## Shapes

The design system adopts a **Soft (Level 1)** corner geometry, utilizing 6px (`rounded-md` / 0.375rem) as the primary radius for interactive elements and standard controls.

### Radius Distribution
- **Controls & Elements (0.375rem / 6px)**: Form inputs, standard buttons, tabs, select triggers, and dropdown menu items.
- **Surface Containers (0.5rem / 8px)**: KPI panels, module cards, tables, modal dialogs, and popovers.
- **Pill Indicators (9999px)**: Status badges, tags, and active toggle track indicators.
- **Focus Indicators**: 2px offset outline with sharp corner preservation mirroring the target geometry.

## Components

### Buttons
- **Primary CTA**: Colored using the active theme accent (`#0284C7` Light / `#38BDF8` Dark by default). Height `2.25rem` (36px), horizontal padding `1rem` (16px), corner radius `6px`. Foreground text `#FFFFFF` (Light) or `#000000` (Dark when high-luminance accents like `#38BDF8` are active). Subtle elevation shadow in light mode.
- **Secondary / Outline**: Background transparent. Border `1px solid #D4D4D8` (Light) / `#3F3F46` (Dark). Foreground text `Text Primary`. Hover triggers subtle neutral overlay `rgba(0, 0, 0, 0.03)` (Light) / `rgba(255, 255, 255, 0.04)` (Dark).
- **Ghost**: Zero border, zero background. Padding identical to default. Hover applies subtle neutral overlay.

### Input Fields & Controls
- Height `2.25rem` (36px), font size `0.875rem`, radius `6px`.
- Resting border `1px solid #D4D4D8` (Light) / `#3F3F46` (Dark).
- Focus state: `1px solid` active accent token with an external `focus:ring-2` matching the active accent color (`#0284C7` / `#38BDF8`).
- Placeholder text bound to `Text Muted` (`#71717A`).

### Checkboxes & Radio Buttons
- Base geometry: 16px × 16px. Checkbox radius `4px`, radio `9999px`.
- Unchecked: `1px solid #D4D4D8` (Light) / `#3F3F46` (Dark), background transparent.
- Checked: Fill with active theme accent, mark glyph rendered in high-contrast neutral.

### Cards & Data Panels
- Background: `#FFFFFF` (Light) / `#18181B` (Dark).
- Border: `1px solid #E4E4E7` (Light) / `#27272A` (Dark).
- Internal padding: `1.25rem` to `1.5rem`.
- KPI Variant: Displays `tabular-kpi` font for primary values with `tabular-sm` tags for positive/negative deltas using strict status tokens (`#10B981` success, `#EF4444` danger).

### Data Tables
- Row height: 40px (compact) to 48px (standard).
- Dividers: `1px solid #E4E4E7` (Light) / `#27272A` (Dark).
- Row hover: Neutral overlay `rgba(0, 0, 0, 0.03)` (Light) / `rgba(255, 255, 255, 0.04)` (Dark).
- Active Row Indicator: Retains hover background and renders a `2px solid` vertical left accent line using the active theme primary token.

### Status Badges & Chips
- Padding: `0.125rem` vertical, `0.5rem` horizontal, radius `9999px`.
- Text: `tabular-sm` or `label-sm`.
- Variant Rules: System status chips use fixed semantic indicators (`#10B981`, `#F59E0B`, `#EF4444`). Category chips use neutral backgrounds with `Text Secondary` foregrounds. Active filtering chips utilize subtle tint fills derived from the current theme accent (`#E0F2FE` Light / `rgba(56, 189, 248, 0.12)` Dark).
