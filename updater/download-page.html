Télécharger l'APK
  1. Après le téléchargement, touchez le fichier dans votre navigateur ou l'app « Fichiers ».
  2. Autorisez l'installation d'applications inconnues pour le navigateur (Android 8+ / API 26+), puis confirmez l'installation.
  3. Ouvrez Aurora et utilisez-le normalement. L'app détecte les prochaines versions toute seule (le self-updater, S8).
